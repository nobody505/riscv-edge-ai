# ASRPRO 完整固定命令版 r2

工程文件：`ASRPRO-小空小空-完整固定命令版-r2.hd`

## 固定词条与 UART0 输出

| 功能 | 语音词条 | 串口输出 |
|---|---|---|
| 唤醒 | 小空小空 | `WAKE\r\n` |
| 打开出行 | 打开出行模式 | `TRAVEL_ON\r\n` |
| 关闭出行 | 关闭出行模式 | `TRAVEL_OFF\r\n` |
| 打开出行 | 打开行路模式 | `TRAVEL_ON\r\n` |
| 关闭出行 | 关闭行路模式 | `TRAVEL_OFF\r\n` |
| 打开出行 | 打开行走模式 | `TRAVEL_ON\r\n` |
| 关闭出行 | 关闭行走模式 | `TRAVEL_OFF\r\n` |
| 打开出行 | 打开出门模式 | `TRAVEL_ON\r\n` |
| 关闭出行 | 关闭出门模式 | `TRAVEL_OFF\r\n` |
| 打开雷达绿灯标记 | 打开灯带 | `LIGHT_ON\r\n` |
| 关闭雷达绿灯标记 | 关闭灯带 | `LIGHT_OFF\r\n` |
| 确认摔倒警报 | 关闭警报 | `FALL_ACK\r\n` |

没有“打开警报”词条。摔倒警报只能由 ADXL345 状态机触发，语音侧只允许确认并关闭当前活动警报。

UART0：115200、8N1、字符串输出。所有 ASRPRO 本地回复语均为空，最终语音反馈继续由 K1 的 TW-TTS 完成。

## 唤醒与自由语音边界

- 使用“唤醒词唤醒”模式，命令窗口 15 秒；固定命令必须先说“小空小空”。
- `导航到 + 任意目的地`、导航多轮目的地、主动短信正文/确认/取消继续由 K1 SenseVoice 识别。
- `TRAVEL_OFF` 同时停止导航和双摄/YOLO；“关闭导航”仍留给板端，只停止导航并保留出行检测。
- `LIGHT_OFF` 只关闭三米外绿色常亮标记；三米内障碍物蓝闪和雷达服务继续运行。
- `FALL_ACK` 只确认当前摔倒警报，不改变导航、出行、雷达绿灯或车辆告警。
